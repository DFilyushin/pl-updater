# get-update-pl

Мониторинг поисковых запросов на pornolab.net: приложение выполняет поиск по
сохранённым запросам и показывает новые (непрочитанные) ветки форума.

## Использование

1. Запустите `get-update-pl.exe` (или `python main.py` из исходников).
2. При первом запуске откроются **Настройки**: заполните логин и пароль
   pornolab, добавьте поисковые запросы, при необходимости укажите папку для
   .torrent-файлов и прокси.
3. Нажмите **«Проверить»** — приложение войдёт на сайт и выполнит все активные
   запросы. Новые темы появятся в таблице и будут накапливаться между запусками.
4. Действия с темами:
   - **двойной клик** — открыть ветку в браузере;
   - **«Скачать торрент»** — скачать .torrent через сессию приложения в папку
     из настроек (работает множественное выделение);
   - **«Подтвердить (прочитано)»** (кнопка, Enter/Delete, контекстное меню) —
     тема считается прочитанной и больше в списке не появится.

Если сайт запросит **капчу**, появится окно с картинкой — введите код вручную.
Автоматического обхода капчи в приложении нет.

## Файлы рядом с exe

- `settings.json` — настройки (внимание: пароль хранится открытым текстом);
- `data.sqlite3` — запросы и найденные темы;
- `cookies.dat` — сессия сайта;
- `app.log` — журнал;
- `debug/` — HTML-дампы при ошибках разбора страниц.

## Разработка

```
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python main.py
```

Сборка exe: `powershell -ExecutionPolicy Bypass -File build.ps1` →
`dist\get-update-pl.exe`.
